使用前，你可能想知道

这是 YASB 本体吗？

这是 YASB 的图形配置器，用来编辑状态栏配置和样式。状态栏与组件的实际运行由 YASB 本体负责。

会覆盖我已经选择的应用设置吗？

已有语言、主题和自定义设置键会保留。新设置补充默认值；备份数量限制按配置目录和文件分别计算。

草稿能在重启后恢复吗？

当前只保留本次运行中的 CSS 草稿。跨重启恢复、外部文件冲突检测和多文件联合保存仍是后续优化项，请在退出前保存修改。

开发快照和正式版有什么区别？

选择 2.0.6 或 2.0.7 可使用对应正式版配置规则。开发快照提供额外字段；例如 adaptive 样式不属于 2.0.7 正式版。内置快照不代表始终同步远端开发分支。
