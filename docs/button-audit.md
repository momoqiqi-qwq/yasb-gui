# 按钮检查与命令预设

本轮检查覆盖当前源码的 XAML 按钮、Python 创建的按钮、弹窗确认/取消入口，以及组件配置中的鼠标回调。逐项事件登记见 [button-bindings.csv](button-bindings.csv)：69 处点击绑定，24 处弹窗主/次按钮及关闭事件绑定，共 93 处。动态循环创建的条目共用绑定，因此此数字不是屏幕上的按钮总数。使用 `NavigateUri` 的链接不需要 `add_click`。

## 发现及修复

1. 普通组件卡片 `MainButton` 没有点击绑定，原来只有 apps 卡片可直接打开编辑器；现已为所有组件绑定编辑入口。停用组件原有点击编辑行为继续保留。
2. apps 浏览添加之前未读取当前启动命令草稿，可能与已经编辑过的条目重复；现先读取草稿，再判断重复。
3. apps 选择文件或图标失败时，通用中文错误翻译可能把系统错误显示为 YAML 解析错误；现在显示具体的应用操作错误。
4. 命令、回调以前只有手工输入；现在提供显式使用的预设选择器。

## 新增预设

12 个点击命令：文件管理器、记事本、计算器、Windows 设置、任务管理器、控制面板、回收站、PowerShell 终端、开始菜单、Windows 搜索、快捷设置、通知中心。

- apps 编辑器：可从预设添加条目，也可“添加自定义命令按钮”。原有名称、图标、启动命令和其他配置保持可编辑。
- 添加组件：在“命令按钮预设”分类选择，生成 `yasb.custom.CustomWidget`；命令只放在 `callbacks.on_left`，`run_cmd=null` 且 `run_once=true`，添加配置时不执行命令。
- 组件表单：鼠标左/中/右回调提供该组件 schema 默认动作及通用命令；不把其他组件的动作混进当前组件。未列出的用户命令继续使用文本编辑。
- `run_cmd`：提供当前时间和计算机/用户两种 JSON 数据预设，输出 `message` 字段，可配合 `{data[message]}` 标签使用；不会定时重复打开应用。
- 选择下拉项后还需点“使用此预设”，不因选择变化自动覆盖输入。

上游执行语义核对：[BaseWidget exec 回调](https://raw.githubusercontent.com/amnweb/yasb/v2.0.7/src/core/widgets/base.py)、[v2.0.7 system_function](https://raw.githubusercontent.com/amnweb/yasb/v2.0.7/src/core/utils/win32/system_function.py)、[v2.0.6 system_function](https://raw.githubusercontent.com/amnweb/yasb/v2.0.6/src/core/utils/win32/system_function.py)。
