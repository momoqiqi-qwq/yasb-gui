# GUI 第一批增强（v0.4.0）

本批实现备份恢复、外部冲突检测、社区扩展管理。拖动排序、批量操作、跨重启草稿恢复、多配置方案、可视化样式、导入向导与真实预览仍属于后续阶段。

## 备份历史

侧栏“备份历史”列出当前配置目录的自动备份，可刷新、打开备份目录、比较差异和恢复单个文件。

- 差异中的减号行来自当前磁盘文件，加号行来自备份。最多展示 2000 行差异。
- 恢复是立即写盘操作，不等待主界面的保存按钮。只恢复所选 config.yaml 或 styles.css。
- 恢复前强制保存当前磁盘文件的备份，即使用户关闭了日常自动备份。
- 此文件还有未保存内容或应用正在保存时，恢复会被阻止；另一文件的未保存内容保留。
- 文件或备份在预览后再次变化时，拒绝恢复，要求重新预览。损坏的 YAML、目录外文件或符号链接不可用作恢复来源。

## 外部修改冲突

加载时记录实际文件内容的 SHA256，保存前检查内容变化，避免仅依赖大小或修改时间。

- 发生冲突时保留草稿并显示磁盘与 GUI 差异。
- “覆盖已查看的磁盘版本”：只授权覆盖预览时的那一版本；如果再次变化，需要重新确认。外部文件仍按既有备份设置备份。
- “重新加载冲突文件”：丢弃所列冲突文件的 GUI 草稿，读取磁盘内容；不影响另一文件的修改。
- “取消”：保持编辑内容，不写盘。
- 异步读取 CSS 后、备份完成后也会复核版本。文件被外部删除同样视为冲突。

## 扩展管理

侧栏“扩展管理”从当前配置中识别本 GUI 生成的设备状态、截图和 Proton VPN 命令。组件重命名和更换 CSS 类名后仍可识别。

- 检查文件路径、基本 PowerShell 依赖、设备程序校验值和截图目录结构。检查不会执行程序、截图或启动 VPN。
- 可重新打开设置，调整程序路径、设备刷新间隔、截图目录及 VPN 托盘模式。
- 重新配置只更新相关执行参数，保留原有标签、CSS 类、其他鼠标回调和扩展选项；仍需主界面保存后生效。
- 手动重写为其他形式的命令可能不能识别，此时继续使用原有组件表单或高级 YAML。
- 依赖检查通过不等于组件运行成功；真实截图与 Proton VPN 弹窗仍需要目标设备验证。

启动页面设置也可选择“备份历史”或“扩展管理”。

## 验证结果

- `python -m pytest -q`：430 通过、1 跳过。
- Ruff 静态检查、编辑器桥接测试、构建、发布包 SHA256/ZIP CRC 与字节码绝对路径扫描通过。
- 独立测试配置中，原生 EXE 的备份预览与恢复、扩展依赖检查与重新配置、冲突取消与明确覆盖通过；外部版本保留到备份，新刷新间隔写入成功。
- 回归测试验证重新加载一个文件时保留另一文件的草稿。测试没有修改实际 YASB 配置，也没有启动 VPN 或执行截图。
