# v0.2.0 发布说明

## 编辑与保存体验

- 新增 9 项持久化设置：启动页面、保存前自动备份、备份保留数量、换行、代码缩略图、行号、CSS 缩进宽度、空白字符和括号着色。
- CSS 切页保留本次运行中的草稿与撤销历史；新增从磁盘重新载入，支持 Ctrl+S。
- 修复空 CSS 无法保存、异步保存提前清除未保存状态，以及保存并退出未等待成功的问题。
- 配置、样式与偏好采用原子写入。保存前默认备份旧文件，按配置目录和文件分别保留最近 10 份，可选择 5/10/20/50 份或关闭备份。
- 保留 YAML 注释并同步已有 schema 指令；修复原生右键菜单和字体、字号互相重置问题。
- 清缓存仅处理 WebView 缓存，保留偏好、日志、备份与 YASB 配置。
- 修复 JSON Schema 资源漏打包造成的启动错误，并移除公开字节码中的本机编译路径。

## 项目介绍

新增中文介绍页、手机布局与可切换的界面示意。更新 README、组件扩展说明、运行步骤与已知限制。

## 下载

推荐下载 **YASB-GUI-0.2.0-x64-portable.zip**，解压后运行 `ygui.exe`。

请保留整个目录的 `lib`、`app`、`assets` 和 DLL 文件。单独 EXE 需要同版本完整包依赖。SHA256 校验见附件。Windows x64 上需要可用的 Windows App SDK Runtime、WebView2 Runtime，以及已经配置好的 YASB 本体。

便携版为本地构建的未签名版本；从旧版升级请解压到新的独立目录。应用内 MSIX 安装流程不适用于这些 ZIP。
