# 配置编辑体验优化（v0.2.0）

当前项目是 YASB 配置器，本次“任务体验”落实为打开、编辑、切页、保存与恢复配置的操作流程。

## 已完成的问题修复

| 原问题 | 影响 | 处理 |
|---|---|---|
| CSS 切页重新读盘 | 未保存草稿及撤销历史丢失 | 复用当前编辑页面；显式重新载入并确认丢弃草稿 |
| 异步读取未完成就标记保存成功 | 误以为写盘成功，保存并退出可能丢失修改 | 等待读取、检查写盘结果，按文件重新计算未保存状态 |
| 空 CSS 被视为无内容 | 无法清空样式文件 | 区分空字符串和读取失败 |
| 直接覆盖文件 | 中途失败可能留下半个文件 | 同目录临时文件、flush/fsync、原子替换 |
| 根配置转为普通 dict | 丢失顶层注释 | 深复制 round-trip 映射并调整顺序 |
| CSS 格式化简单压缩空白 | 可能改变引号内文本 | 使用 Monaco 格式器，保留撤销步骤 |
| 右键菜单依赖不存在的 window.editor | 原生复制、粘贴、格式化等入口失效 | 显式公开初始化完成的编辑器实例 |
| 改字号会重置字体，反之亦然 | 设置互相覆盖 | 只更新发生变化的属性 |
| 清理缓存删除整个应用数据目录 | 语言、主题、日志等丢失 | 仅清理 WebView 缓存；未保存时阻止清理重启 |

## 新增设置

在“应用设置”的“编辑器设置”和“编辑与保存”中提供 9 项设置：

- 启动页面：全局、状态栏、组件、样式、应用设置。
- 保存前自动备份：默认开启，分别备份旧 config.yaml 或 styles.css。
- 备份数量：每个配置目录、每种文件分别保留 5/10/20/50 份，默认 10 份；下次保存时整理。
- 自动换行、代码缩略图、普通/相对/隐藏行号。
- CSS 缩进宽度：2/4/8 空格；YAML 保持 2 空格。
- 空白字符显示：关闭、仅选中、全部。
- 括号配对着色。

编辑器设置在下次打开组件 YAML 编辑器时应用，CSS 编辑器即时应用。保存的既有偏好和自定义设置键保留。草稿仅保留于本次运行中。

备份位于应用数据目录下的 `YASB-GUI/backups/<配置目录标识>/`，可从设置页直接打开。恢复时先关闭配置器，复制所需 `.bak` 内容回对应配置文件。备份不上传。

## 后续优先优化

1. 草稿自动恢复：异常退出后恢复未保存内容，需区分草稿和实际配置。
2. 外部修改冲突检测：保存前检测磁盘版本，支持比较和选择保留内容。
3. 多文件保存一致性：目前每个文件独立原子替换；配置成功而样式失败时保留样式未保存提示，尚无联合事务。
4. schema 缓存一致性：下载后失效相关缓存并同步已打开表单。
5. CSS 注释清理：当前简单正则可能误删字符串中类似注释的内容，后续使用语法解析。
6. 组件批量操作与筛选：增加按类型、状态栏、启用状态筛选和批量调整，减少重复编辑。
