# YASBGUI 界面动画

按反馈层级统一处理，保留 WinUI 的原生按钮配色和 ContentDialog 动画：

- 按钮按压：80ms，缩放至 0.97；鼠标、触摸和键盘通过 WinUI IsPressed 状态触发，不拦截 Click。
- 组件卡片悬停：200ms，最多缩放至 1.008，轻微回弹。每侧最多增长 3 DIP，卡片预留 4 DIP 边距，避免宽窗口下放大后裁剪图标。
- 页面切换：240ms，透明度 0→1，向上移动 12 DIP。只在导航实际更换内容时播放，快速切页中断旧动画，不排队或阻塞导航。
- 组件排序：立即更新配置和刷新列表；去掉等待旧排序动画结束才修改数据的路径，保留按钮按压反馈。

普通、强调、图标、图标文字和危险按钮的工厂入口都接入了按压反馈；组件卡片、组件选择列表与保存/放弃按钮也接入。第三方特性显式设置的 RenderTransform 保留，不覆盖它们。

“设置 → 编辑与保存 → 界面动画”可以开启或关闭。关闭时停止正在运行的自定义动画并恢复正常尺寸和透明度；即使开启，也遵循 Windows 的客户端区域动画设置。设置只影响 YASBGUI，不写入 YASB 配置或修改工具栏的动画。

控件卸载时取消动画并移除属性回调、恢复原变换；缓存页面重新显示时重新绑定。动画只作用于透明度和绘制变换，不逐帧修改布局尺寸。

实现：`app/ui/motion.py`，通过控件工厂、组件页和应用导航入口调用。无需新增依赖。

验证：

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe tests/native_motion_smoke.py
.venv/Scripts/python.exe work/ui_smoke.py
.venv/Scripts/python.exe work/button_preset_smoke.py
```

原生动效检查验证真实 WinUI 缩放、透明度和位移动画时钟、快速重复切换、禁用控件恢复、系统/应用关闭动画、控件卸载和重载，以及动画过程中点击即时执行。原生界面检查覆盖全部版本的组件表单和主要设置页。按压动画的时钟通过测试入口触发，未自动发送鼠标或键盘输入。
